# FloorVoice

Voice-first front end to ERPNext for shop-floor workers: hold a button, speak in Tamil,
English or a mix, and a Muse Spark agent posts the ERPNext transaction and reads back a
one-line confirmation. Built for the Meta Global AI Developer Hackathon (Oct 30 – Nov 4, 2026).

*Work in progress — full README (architecture, setup, limitations) lands on Day 5.*

## What was built during the hackathon
All code in this repository was written between Oct 30 and Nov 3, 2026, during the event.
ERPNext / Frappe is a pre-existing open-source dependency (GPLv3) and is not part of this work.
